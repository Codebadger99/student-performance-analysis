# Student Performance Analysis

This project analyzes factors that may influence a student's final exam score. The dataset contains information about study habits, family background, school conditions, and student characteristics.

## Dataset Overview

The dataset includes 20 input features and one target variable: `Exam_Score`.

## Attributes and Their Meaning

| Attribute | Description |
| --- | --- |
| `Hours_Studied` | Number of hours a student spends studying each week. |
| `Attendance` | Percentage of classes the student attends. |
| `Parental_Involvement` | How involved the parents are in the student’s education. Values: Low, Medium, High. |
| `Access_to_Resources` | Whether the student has access to learning resources. Values: Low, Medium, High. |
| `Extracurricular_Activities` | Whether the student takes part in extracurricular activities. Values: Yes or No. |
| `Sleep_Hours` | Average number of hours of sleep the student gets each night. |
| `Previous_Scores` | The student’s scores from earlier exams. |
| `Motivation_Level` | The student’s level of motivation. Values: Low, Medium, High. |
| `Internet_Access` | Whether the student has internet access. Values: Yes or No. |
| `Tutoring_Sessions` | Number of tutoring sessions the student attends each month. |
| `Family_Income` | The family’s income level. Values: Low, Medium, High. |
| `Teacher_Quality` | The quality of the teachers in the student’s school. Values: Low, Medium, High. |
| `School_Type` | The type of school the student attends. Values: Public or Private. |
| `Peer_Influence` | Whether friends affect the student’s academic performance. Values: Positive, Neutral, Negative. |
| `Physical_Activity` | Average number of hours the student spends on physical activity each week. |
| `Learning_Disabilities` | Whether the student has a learning disability. Values: Yes or No. |
| `Parental_Education_Level` | Highest education level reached by the student’s parents. Values: High School, College, Postgraduate. |
| `Distance_from_Home` | Distance from home to school. Values: Near, Moderate, Far. |
| `Gender` | Student’s gender. Values: Male or Female. |
| `Exam_Score` | Final exam score for the student. This is the target variable. |

## Why This Dataset Matters

This dataset can be used to study how different factors affect academic performance. For example, it helps answer questions like:

- Do students who study more tend to score higher?
- Does attendance or sleep influence results?
- How do parental involvement and access to resources affect performance?
- Which factors are most strongly related to exam success?

## Suggested Use

This data is well suited for:

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature correlation analysis
- Predictive modeling
- Identifying key factors that influence exam performance

## Target Variable

The main variable of interest is `Exam_Score`, which represents the final academic result. The other columns are considered predictors or influencing factors.
